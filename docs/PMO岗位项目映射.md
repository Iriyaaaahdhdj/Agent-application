# PMO / AI 产品岗位项目映射

## 岗位关键词

- AI Chatbot 配置、测试、优化
- AI CRM 工作流
- 用户漏斗分析
- 增长实验追踪
- 用户研究、问卷、可用性测试
- 数据看板、周报、复盘
- 跨团队沟通和项目推进

## 本项目可对应的能力

| 岗位能力 | 项目证据 |
|---|---|
| AI Chatbot 流程测试 | 主程序支持用户问题输入、问题类型识别、模型回答和报告生成 |
| Prompt 调优 | Prompt 中定义问题分类、资料约束、JSON 输出格式和复习计划 |
| Badcase 分析 | `data/eval_cases.csv` 记录失败类型和优化建议 |
| 数据评估 | `scripts/evaluate_cases.py` 自动统计不同 Prompt 版本效果 |
| 产品文档 | README、测试记录、评测报告说明产品目标和迭代方向 |
| 自动化通知 | 飞书通知模块可类比 CRM/团队协作触达 |

## 面试讲法

我做这个项目时，不只是调用模型回答问题，而是把它当成一个小型 AI 工具来拆：先定义用户场景，再拆问题类型和边界场景，接着设计 Prompt、输出结构和评测字段，最后用测试样例记录回答质量、格式通过率、拒答表现和 badcase。这个过程和岗位里 AI Chatbot 配置、测试、优化，以及基于反馈迭代流程比较接近。
