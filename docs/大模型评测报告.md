# AI Agent 问答评测设计

## 评测目的

这个评测不是为了证明模型「很强」，而是为了回答三个产品问题：

1. 用户问课程资料相关问题时，回答是否可用。
2. 用户要求指定格式时，系统是否稳定遵守。
3. 用户问资料没有覆盖的问题时，系统是否知道拒答或标注边界。

## 样例设计

评测集放在 `data/eval_cases.csv`，当前包含 30 条样例，按以下维度分层：

| 维度 | 取值 | 说明 |
|---|---|---|
| task_group | 概念解释、流程梳理、资料定位、复习规划、格式约束、边界拒答等 | 覆盖真实学习助手高频任务 |
| difficulty | easy、medium、hard | 区分普通问答和边界/格式压力测试 |
| source_scope | in_scope、out_of_scope、mixed | 判断问题是否被资料覆盖 |
| prompt_version | V1、V2、V3 | 记录不同 Prompt 策略的表现 |

## 字段说明

| 字段 | 用途 |
|---|---|
| user_query | 用户输入问题 |
| expected_intent | 这条样例真正要完成的任务 |
| must_have | 合格回答必须包含的要点 |
| should_not | 明确不希望出现的行为 |
| human_score | 人工可用性评分，1-5 分 |
| answer_groundedness | 回答依据充分性，1-5 分 |
| format_pass | 是否符合指定格式 |
| refusal_pass | 边界问题是否正确拒答 |
| latency_ms | 单轮生成耗时 |
| badcase_type | 失败归因 |
| review_note | 人工复核备注 |

## Prompt 迭代

| 版本 | 策略 | 观察 |
|---|---|---|
| V1 | 通用课程助教 Prompt | 能回答基础问题，但容易泛化，资料缺失时拒答弱 |
| V2 | 增加任务类型拆分 | 结构稳定性提升，适合复习规划、面试表达等任务 |
| V3 | 增加资料边界和拒答规则 | 边界问题表现更稳，但仍需要引用片段和格式校验 |

## 评测方法

运行：

```bash
python scripts/evaluate_cases.py
```

脚本会读取 `data/eval_cases.csv`，输出：

- 总体平均分
- 4 分及以上占比
- 依据充分性
- 格式通过率
- 拒答通过率
- 平均耗时
- 按 Prompt 版本、任务类型、资料覆盖范围分组的指标
- badcase Top 和后续 Backlog

输出报告：

```text
docs/大模型评测结果汇总.md
```

## 目前结论

当前评测显示，Agent 的基础问答和项目解释类任务表现较好；主要短板集中在资料定位、资料缺失拒答和结构化输出稳定性。

下一步优先做三件事：

1. 给课程资料切片并编号，让回答能带引用。
2. 对 JSON/表格类输出做 schema 校验。
3. 增加用户反馈记录，把人工复核变成持续迭代数据。
